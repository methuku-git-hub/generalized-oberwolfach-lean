3 Checked finite stability arguments

Definition 3.1 Common neighbourhoods on a fixed domain
✓
#

Lean declarations

  • Oberwolfach.common
  • Oberwolfach.changed

For finite \(A,J\) and a family of finite sets \((N_j)\), put \(C(A,J,N)=\{ v\in A:\forall j\in J,\ v\in N_j\} \). The empty intersection is \(A\). Put \(\operatorname {changed}(X,Y)=(X\setminus Y)\cup (Y\setminus X)\).

Lemma 3.2 Neighbourhood stability and arbitrary later deletion
✓
#

Uses

  • Definition 3.1

Lean declarations

  • Oberwolfach.neighbourhood_stability_with_deletion

If \(|N_j\triangle N'_j|\le b\) for every \(j\in J\) and \(||C(A,J,N)|-\mu |\le e\), then

\[ \big||C(A,J,N')|-\mu \big|\le e+|J|b, \qquad |C(A,J,N')\setminus D|\ge \mu -e-|J|b-|D| \]

for every finite \(D\), including a set chosen after \(N,N'\).

Manuscript label: lem:pr:rt1-stability.

Proof ▼

The symmetric difference of the two common neighbourhoods is contained in \(\bigcup _{j\in J}(N_j\triangle N'_j)\). Bound this union by the sum of its sizes and apply the triangle inequality. Deleting \(D\) removes at most \(|D|\) vertices. There is no sampling factor in this deterministic loss and no change of the ambient normalization.

Definition 3.3 Fixed weighted products
✓
#

Lean declarations

  • Oberwolfach.patternValue

For a finite coordinate set \(F\), states \(\rho _e\) and required states \(s_e\), put \(p_F(\rho )=\prod _{e\in F}\mathbf1_{\{ \rho _e=s_e\} }\). The state type may depend on \(e\). The coordinate universe itself need not be finite, since all tested coordinate sets are finite. Required states are supplied as total functions; in the manuscript’s formulation, partial required states can be extended outside \(F\) using the assumed nonempty state spaces. Their values outside \(F\) are unused.

Lemma 3.4 Changes of weighted products
✓
#

Uses

  • Definition 3.3

Lean declarations

  • Oberwolfach.weighted_product_stability

Let \(w_i\ge 0\) and finite candidate coordinate sets \(F_i\) be fixed. If \(\sigma _e=\tau _e\) whenever \(e\in F_i\setminus D\), for every tested candidate \(i\), then

\[ \left|\sum _iw_ip_{F_i}(\tau )-\sum _iw_ip_{F_i}(\sigma )\right| \le \sum _{e\in D}\sum _{i:e\in F_i}w_i. \]

Manuscript label: lem:pr:wi-stability.

Proof ▼

Each product belongs to \(\{ 0,1\} \). It is unchanged if \(F_i\cap D\) is empty; otherwise its change has absolute value at most one, which is at most \(|F_i\cap D|\). Multiply by \(w_i\), sum, use the triangle inequality and interchange the two finite sums.

Lemma 3.5 Omitted-root products
✓
#

Uses

  • Lemma 3.4

Lean declarations

  • Oberwolfach.omitted_root_stability

For fixed omitted coordinates \(R\), replace each \(F_i\) by \(F_i\setminus R\). The same estimate holds with right-hand side \(\sum _{e\in D}\sum _{i:e\in F_i\setminus R}w_i\). The two assignments may differ arbitrarily on \(R\), and neither is conditioned on root presence. All weights remain fixed.

Proof ▼

Apply the preceding theorem to the finite sets \(F_i\setminus R\).
