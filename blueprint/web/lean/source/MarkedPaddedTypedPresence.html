  16     (C:MarkedCycleTuple tail head ktail khead m π b) (k:Fin (m+1)):
  17     if k=Fin.last m then ∃ e,ktail e=C.val k∧khead e=C.val (finRotate (m+1) k)
  18     else ∃ e,tail e=C.val k∧head e=C.val (finRotate (m+1) k):=by

  21   · simpa only [Fin.castSucc_ne_last,ite_false,finRotate_castSucc_eq_succ] using C.property.2.1 q

  30 theorem padded_typed_presence (src dst:A→V) (row:S→V) (jr:A→Bool) (js:S→Bool) (u:S→U)
  31     (C:I→MarkedWheel tail head ktail khead m π b H₀ HK)
  32     (hr:∀ a,if jr a then ∃ e,ktail e=src a∧khead e=dst a else ∃ e,tail e=src a∧head e=dst a)
  33     (hs:∀ s,if js s then HK (row s) (u s) else H₀ (row s) (u s)):
  34     (∀ a,if paddingRimType jr m a then
  35       ∃ e,ktail e=paddingRimTail src (fun i=>(C i).1.val) a∧khead e=paddingRimHead dst (fun i=>(C i).1.val) a
  36       else ∃ e,tail e=paddingRimTail src (fun i=>(C i).1.val) a∧head e=paddingRimHead dst (fun i=>(C i).1.val) a)∧
  37     ∀ s,if paddingSpokeType js m s then
  38       HK (paddingSpokeRow row (fun i=>(C i).1.val) s) (actualPaddingSpokeHub u (fun i=>(C i).2.val) s)
  39       else H₀ (paddingSpokeRow row (fun i=>(C i).1.val) s) (actualPaddingSpokeHub u (fun i=>(C i).2.val) s):=by
