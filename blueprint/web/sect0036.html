E.18 A fixed absorber in a changed host

Lemma E.508 Encoded-host typed containment
✓
#

Lean declarations

  • Oberwolfach.marked_encoded_host_typed_containment_iff
  • Oberwolfach.marked_encoded_host_typed_containment_iff_outside

For an encoded typed host agreeing with the original sample on the protected inner pair, containment of all its typed rim arcs in the original sample is equivalent to checking the supplied arcs outside that pair. This is a criterion, not a proof that the actual preparation host is contained in the sample.

Proof ▼

The encoding identifies precisely the supplied ordinary and marked arcs. On the inner pair the stated agreement supplies their membership in the sample.

Lemma E.509 Choosing the terminal reservoir before the host
✓
#

Lean declarations

  • Oberwolfach.marked_choose_reserved_terminal_reservoir

For a fixed terminal pair and a larger excluded pair, the reserved-absorber property supplies one bounded reservoir that works for every divisible typed remainder on the terminal pair. The reservoir is chosen before any later host.

Proof ▼

Apply the reserved-absorber property to the complete family of typed arcs and spokes on the fixed terminal pair.

Lemma E.510 Reserved absorber in a changed host
✓
#

Lean declarations

  • Oberwolfach.marked_reserved_terminal_absorber_in_ambient_host
  • Oberwolfach.marked_reserved_terminal_completion_in_modified_subhost
  • Oberwolfach.marked_reserved_absorber_deletion_in_changed_host

A reservoir selected in a source host may be transferred to a later host that preserves its typed resources, even if the later host has additional edges. The reservoir avoids the larger protected pair. Deleting its wheel decomposition before cover-down preserves the inner induced resources, the displayed incidence budgets and divisibility.

Proof ▼

Transfer the actual typed resources, then apply the physical deletion and remainder identities.

Lemma E.511 Iteration with a fixed transferred absorber
✓
#

Lean declarations

  • Oberwolfach.marked_reference_iteration_with_fixed_transferred_absorber

Given the stated reference-level data and step properties, a fixed reservoir chosen in another typed host absorbs the final remainder of the finite iteration whenever its typed resources are preserved and the final typed remainder agrees with the source host.

Proof ▼

Iterate the physical deletions, transfer the final typed remainder and combine the disjoint decompositions.

Lemma E.512 Completion with a fixed transferred absorber
✓
#

Lean declarations

  • Oberwolfach.marked_reference_completion_with_fixed_transferred_absorber

A changed divisible host has a marked wheel decomposition under the displayed fixed-level, typed-agreement and deletion-budget hypotheses. The fixed source-host reservoir is removed before the first cover-down and is used after the finite iteration. This statement does not construct those level inputs or prove the main theorem.

Proof ▼

Transfer and remove the reservoir, run the fixed-reservoir iteration and reunite its resources with the remainder.

Lemma E.513 Terminal typed agreement on the protected pair
✓
#

Lean declarations

  • Oberwolfach.marked_encoded_host_terminal_arc_agreement
  • Oberwolfach.marked_terminal_spoke_agreement

Every terminal ordinary or marked arc of the encoded host on the protected pair has an arc of the same endpoints and type in the original sample. Agreement of the two spoke types on the protected pair gives the corresponding terminal spoke agreement.

Proof ▼

Use the prescribed inner agreement, and restrict it to the fixed terminal pair.
